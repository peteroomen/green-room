Built on good foundations.

Stockfish 19

The browser engine is Stockfish.js 19.0.0, lite single-thread WASM, licensed under GPLv3. The exact package is pinned and copied during installation. Read the licence. Source and build instructions. Stockfish is free software; LLM providers charge separately for API use.

Puzzles

300 curated puzzles from the Lichess puzzle database, released under CC0. Each puzzle links to its source game. The first move in the dataset is played before the puzzle begins. Ratings are from the dataset snapshot and are approximate.

Interface and chess rules

React, Vite, chess.js (BSD-2-Clause), react-chessboard (MIT), shadcn/ui and Radix (MIT), assistant-ui (MIT), Vercel AI SDK (Apache-2.0), Lucide (ISC), and Inter (SIL Open Font License). These projects retain their respective licences.
