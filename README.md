# Greenroom

A personal chess room for playing, understanding and practising chess. React, TypeScript, Vite, Stockfish and Claude. Built for a learner around 900–1100.

## Implementation scope

1. Play Stockfish at different strengths or an LLM with legal chess tools and no engine access.
2. Adjustable coaching, before/after move guidance, engine-grounded explanation and explorable variations.
3. PGN import/export and retrospective review with key moments and lessons.
4. Lichess puzzles, personal mistake practice, openings and endgames, with local saves and backup.

Implementation is in progress. Source checkpoints are committed here as work proceeds. No API secrets belong in this repository.
